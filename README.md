# Master Trans Website

Статическая локальная версия сайта Master Trans.

## Локальный запуск

```bash
python3 -m http.server 8080
```

После запуска сайт доступен по адресу <http://localhost:8080/>.

## Основные файлы

- `index.html` — главная страница.
- `home-exact.js` — интерактивность главной страницы.
- `rebrand_home.py` — скрипт формирования брендированной главной страницы.
- `images/`, `svg/`, `fonts/`, `_nuxt3/` — локальные ресурсы сайта.
